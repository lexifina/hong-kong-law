# 32. Access to Security Council document S/2006/814, etc.

The Director-General of Trade and Industry is to make available at his office, for inspection by the public during normal office hours, free of charge, an English version and a Chinese version of each of the following documents—

- (a) the Security Council document S/2006/814;

- (b) the Security Council document S/2006/815;

- (c) the Security Council document S/2006/853;

- (d) the Security Council document S/2006/853/Corr.1.

# 5. Contents of plan

The plan shall delineate and describe the parcels and plots in so far as is possible from existing records and the data and information obtained and shall—

- (a) indicate the position of each parcel and that of any plot set aside in association with the demise thereof;

- (b) give as far as practicable the current postal address of each parcel and any such plot;

- (c) give any other available information relevant to the establishment of the position of the parcels and plots.

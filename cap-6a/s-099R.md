# 99R. Time for lodging proxy

(1) A proxy may not be used unless it is deposited with the trustee 24 hours before the meeting at which it is to be used.

(2) A proxy required to be deposited in accordance with these rules shall be deemed to have been so deposited if such proxy is received by facsimile transmission by the trustee within the time provided in subrule (1). (L.N. 150 of 2014)

(L.N. 77 of 1998; L.N. 123 of 2007)

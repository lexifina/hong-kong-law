# 6. Application to set aside for irregularity

(1) An application to set aside for irregularity a proceeding, a step taken in a proceeding or a document, judgment or order in a proceeding must not be allowed unless it is made—

- (a) within a reasonable time; and

- (b) before the party applying has taken any fresh step after becoming aware of the irregularity.

(2) An application under this rule may be made by summons and the grounds on which the application is made must be stated in the summons.

# 4. Prescribed classes of library under section 7(5)

(1) Each of the classes of library specified in the First or Second Schedule shall be a class prescribed for the purposes of section 7(5) of the Act and, for the purposes of paragraph (a) of that subsection (which relates to the librarian to whom a copy is supplied), and any class of library so specified shall, where appropriate, be deemed to include any library of a similar class situated outside Hong Kong.

(2) This regulation shall apply to any library of a class so specified whether established or conducted for profit or not.

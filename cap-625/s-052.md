# 52. Commissioner to issue code of practice

(1) The Commissioner may issue a code of practice—

- (a) indicating the manner in which the Commissioner proposes to perform a function or exercise a power; or

- (b) providing guidance on the operation of a provision of this Ordinance.

(2) The Commissioner—

- (a) must publish the code of practice in a manner appropriate to bringing it to the notice of persons affected by it; and

- (b) must make copies of the code of practice available to the public (in hard copy or electronic form).

(3) The Commissioner may amend or revoke the code of practice. Subsections (2) and (4) apply to an amendment or revocation of the code of practice in the same way as they apply to the code of practice.

(4) A code of practice issued under this section is not subsidiary legislation.

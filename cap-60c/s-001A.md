# 1A. Application of this notice to Ozone Layer Protection Ordinance

In this notice, a reference to—

- (a) “import licence” is a reference to an import licence or an import and export licence issued under the Ozone Layer Protection Ordinance (Cap. 403); and

- (b) “export licence” is a reference to an export licence or an import and export licence issued under the Ozone Layer Protection Ordinance (Cap. 403).

(33 of 2003 s. 2)

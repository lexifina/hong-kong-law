# 2. Interpretation

In these Rules, unless the context otherwise requires—

- “authorized institution” (認可機構) has the same meaning as in the Banking Ordinance (Cap. 155);

- “futures or options clearing house” (期貨或期權結算所) has the same meaning as in the Financial Resources Rules (L.N. 103 of 2000) ; (L.N. 102 of 2000)

- “liquid capital” (速動資金) has the same meaning as in the Financial Resources Rules (Cap. 24 sub. leg.). (L.N. 102 of 2000)

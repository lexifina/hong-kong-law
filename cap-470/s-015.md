# 15. Approval of Director before first installation

Before a builder’s lift or tower working platform is installed for the first time in Hong Kong, the registered contractor responsible for the installation shall—

- (a) submit the following to the Director—

  - (i) basic design details and technical data as specified by the Director;

  - (ii) a copy of the maintenance manual;

  - (iii) test certificates in respect of the driving machine brake, overspeed governor, safety gear and rack and pinion suspension system issued by an institution which is acceptable to the Director; and

- (b) obtain the written approval of the Director.

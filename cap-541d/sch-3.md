Forms of Ballot Papers for a General Election/By-election

Form 1

Ballot Paper for Geographical Constituency

- # A code will be assigned to each of the geographical constituencies. Only the appropriate code will be printed.

- * Only the appropriate information will be printed.

Ballot Paper for Functional Constituency

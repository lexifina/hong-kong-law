# 274. Effective number of underlying exposures

For the purposes of the supervisory formula, an authorized institution which has securitization exposures in respect of a securitization transaction shall—

- (a) use Formula 24 set out in section 262 to calculate the effective number of underlying exposures in the transaction;

- (b) treat multiple exposures to one obligor as one exposure; and

- (c) if the transaction is a re-securitization transaction, use Formula 24 in accordance with section 262(7).

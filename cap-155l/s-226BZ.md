# 226BZ. Treatments of supervisory factor for basis transactions and volatility transactions

The supervisory factor applicable to an asset class, a hedging set, a subset or an entity, when used in calculating the add-on for a hedging set in an asset class or for a subset in a hedging set, must be adjusted by multiplying the supervisory factor by—

- (a) if the hedging set consists of basis transactions—one-half; or

- (b) if the hedging set consists of volatility transactions—5.

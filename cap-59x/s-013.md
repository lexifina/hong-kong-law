# 13. Requirements relating to use of respiratory protective equipment

No proprietor of an industrial undertaking who uses an asbestos process shall—

- (a) provide respiratory protective equipment for the use of any person which has been used by another person, unless it has first been thoroughly cleaned and disinfected; or

- (b) employ any person to perform any work for which respiratory protective equipment is required to be provided unless that person has been fully instructed in the proper use of that equipment.

# 5. Special power to issue certificates of exemption in respect of building works

Subject to the provisions of this Ordinance, the Director shall issue a certificate of exemption in respect of building works in the New Territories—

- (a) for a building to be built by any person and to be used for non-industrial purposes;

- (b) for a building to be built by a community organization for the use of the community;

- (c) for a building to be built on agricultural land and to be used solely for agricultural purposes;

- (d) for the replacement of a temporary structure in the New Territories.

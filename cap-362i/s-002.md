# 2. Interpretation

In this Order—

- “HS code” (協調制度編號) means the code described as item code in the Hong Kong Imports and Exports Classification List (Harmonized System) issued by the Commissioner of Customs and Excise by notice G.N.(S.) 139 of 2001 published in the Gazette, as amended by notices G.N.(S.) 137 of 2002 and G.N.(S.) 102 of 2003 published in the Gazette;

- “textile made-up article” (紡織製成品) means—

  - (a) any article which under the Hong Kong Imports and Exports Classification List (Harmonized System) has been assigned an HS code the first 6 digits of which are specified in the Schedule; and

  - (b) any baby napkin which under the Hong Kong Imports and Exports Classification List (Harmonized System) has been assigned an HS code the first 6 digits of which is 620920.

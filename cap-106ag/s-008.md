# 8. Spectrum utilization fee not payable for use of spectrum relating to space object

(1) If a user of the spectrum that falls within the frequency band 3400–3600 MHz is authorized by the Authority to use the spectrum for the sole purpose of telemetry, tracking, control, monitoring and testing functions related to the use, maintenance, operation and control of space objects, the user is not liable to pay any spectrum utilization fee for using the spectrum solely for that purpose.

(2) In this section—

- space object (空間物體) has the meaning given by section 2(1) of the Outer Space Ordinance (Cap. 523).

# 72. Contents of the search report

A search report shall—

- (a) identify by name the searching authority which prepared the report;

- (b) be dated and shall indicate the date on which the search was actually completed;

- (c) contain the classification of the subject-matter according to the International Patent Classification;

- (d) contain the citations of the documents considered to be relevant;

- (e) list the classification identification of the fields searched;

- (f) contain the name of the officer of the searching authority responsible for the report.

# 7. Entries in an Election Committee register to be in Chinese or English

In an Election Committee register, the name of a member is to be recorded— (L.N. 200 of 2001)

- (a) in Chinese—

  - (i) if the member’s principal residential address on the application to be registered as an elector for a functional constituency is in Chinese;

  - (ii) if the member has not applied to be so registered, if the member’s principal residential address on the application to be registered as a voter for a subsector is in Chinese; or

  - (iii) if the member—

    - (A) is a nominee for the religious subsector or an ex-officio member; and

    - (B) has not applied to be registered as an elector or a voter,

  - if the member’s principal residential address on the application to be registered for a geographical constituency is in Chinese; or

- (b) in English, if the member’s principal residential address on the relevant application referred to in paragraph (a) is in English. (L.N. 255 of 2002)

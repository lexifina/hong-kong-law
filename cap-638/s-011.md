## Subdivision 2 Application

# 11. Application of Part 5

(1) This Part applies only in relation to an e-proceeding.

(2) A proceeding is an e-proceeding—

- (a) if—

  - (i) an implementation notice is published stating that the use of electronic technology has been implemented for all proceedings in an e-Court; and

  - (ii) the proceeding is in that e-Court;

- (b) if—

  - (i) an implementation notice is published stating that the use of electronic technology has been implemented for a type or description of proceeding in an e-Court; and

  - (ii) the proceeding is in that e-Court and is of that type or description; or

- (c) if—

  - (i) an implementation notice is published stating that the use of electronic technology has been implemented for a type or description of proceeding in an e-Court at a venue; and

  - (ii) the proceeding is in that e-Court at the venue and is of that type or description.

# 7A. Offences in respect of trade description of services

(1) A trader who—

- (a) applies a false trade description to a service supplied or offered to be supplied to a consumer; or

- (b) supplies or offers to supply to a consumer a service to which a false trade description is applied,

commits an offence.

(2) In this section—

- service (服務) does not include any service covered by Schedule 4.

(Added 25 of 2012 s. 8)

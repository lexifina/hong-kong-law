# 45. Returns

(1) The Commission may make rules under section 73 for the purposes of this section requiring any licensed leveraged foreign exchange trader to make returns to the Commission.

(2) Rules made for the purposes of this section may—

- (a) apply to licensed leveraged foreign exchange traders generally or to licensed leveraged foreign exchange traders of a particular class or description specified in the rules, and different rules may be made in respect of such different classes or descriptions;

- (b) specify the form of the return and the particulars it is to contain and the persons by whom such returns are to be made;

- (c) specify the occasions when a return is required; and

- (d) specify the time by which a return required by the rules is to be received by the Commission.

(3)

- In this section “licensed leveraged foreign exchange trader” (持牌槓桿式外匯買賣商) includes a representative.

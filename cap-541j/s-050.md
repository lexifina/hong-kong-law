# 50. Ballot papers not to be counted

When counting the votes, any ballot paper—

- (a) on which there is any writing or mark by which the elector can be identified;

- (b) which has the words “TENDERED” and “重複” endorsed on it;

- (c) which has the words “SPOILT” and “損壞” endorsed on it;

- (d) which has the words “UNUSED” and “未用” endorsed on it;

- (e) which is substantially mutilated;

- (f) which is unmarked;

- (g) which is not marked in accordance with section 36(1)(b);

- (h) which the Returning Officer determines as being void for uncertainty,

shall not be counted.

# 42. Ballot paper account

The Presiding Officer shall prepare a statement which shall—

- (a) be in the specified form; and

- (b) show the number of ballot papers supplied under section 22(2) and account for those ballot papers under the following heads—

  - (i) the number of ballot papers estimated by the Presiding Officer to be in the ballot box;

  - (ii) the number of ballot papers which have not been issued;

  - (iii) the number of unused ballot papers; and

  - (iv) the number of the spoilt ballot papers.

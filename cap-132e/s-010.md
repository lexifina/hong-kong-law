# 10. Reservation of areas for swimmers

(1) The Council may set aside for the sole use of swimmers the whole or any part of the waters adjacent to any bathing beach.

(2) Where any waters are set aside under paragraph (1), the Council shall cause the area so set aside to be demarcated in such suitable manner as, in the opinion of the Council, will best draw thereto the attention of persons using the beach:

- Provided that, where the whole of the waters adjacent to any beach are so set aside, it shall be sufficient to post a notice to that effect in any conspicuous place upon the beach.

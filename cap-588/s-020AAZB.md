# 20AAZB. Current registration remains in force until decision on renewal takes effect

(1) This section applies if a renewal application (CPA firm registration) has been made but the application is not finally determined before the expiry of the current registration.

(2) Despite section 20AAW(1), the current registration remains in force until—

- (a) if the registration is renewed—the day on which the renewal takes effect under section 20AAZC; or

- (b) if the application is refused—the day on which the refusal takes effect under Part 3C.

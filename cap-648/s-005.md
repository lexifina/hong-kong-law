# 5. Special purpose lease cancellation note

(1) If an SPL identification note is made in relation to a lease, but subsequently the lease is no longer, or should not be regarded as, a special purpose lease, the Director must then cause a special purpose lease cancellation note to be made in the Register in relation to the lease to cancel the SPL identification note.

(2) The SPL cancellation note must—

- (a) state that the SPL cancellation note cancels the SPL identification note made in relation to the lease for the purposes of this Ordinance;

- (b) state the date on which the SPL identification note is made; and

- (c) state the date on which the SPL cancellation note is made.

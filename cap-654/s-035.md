# 35. Transitional arrangements for existing proceedings that are NS proceedings

(1) For an existing proceeding that is an NS proceeding—

- (a) every application made before the commencement date under the subject provision in the proceeding is to be regarded as having been withdrawn;

- (b) every application otherwise made before the commencement date for the proceeding to be conducted remotely is to be regarded as having been withdrawn;

- (c) as long as a verdict has not yet been delivered in the proceeding, every permission given under the pre-amended subject provision in the proceeding is to be regarded as having never been given; and

- (d) as long as a final judgment has not yet been rendered in the proceeding, every order otherwise made before the commencement date for the proceeding to be conducted remotely is to be regarded as having never been made.

(2) In this section—

- pre-amended subject provision (修訂前的標的條文) means section 79I of Cap. 221 as in force immediately before 23 March 2024.

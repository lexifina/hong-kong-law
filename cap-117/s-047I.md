# 47I. Instrument to be duly stamped

An instrument to which section 47F(1) or 47G(1) applies is not duly stamped unless—

- (a) it is stamped with the stamp duty with which it would be chargeable but for section 47F or 47G; or

- (b) it has, in accordance with section 13, been stamped with a particular stamp or by way of a stamp certificate, denoting either that it is not chargeable with any stamp duty or that it is duly stamped.

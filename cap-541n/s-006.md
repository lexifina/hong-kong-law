# 6. Part processing of claims

If an auditor’s report presented under section 3(4) states that only part of the election return complies with the requirements set out in section 37(1) and (2)(b) of the Elections (Corrupt and Illegal Conduct) Ordinance (Cap. 554), the Chief Electoral Officer may process that part of the return that complies with those requirements and stop processing the part of the return that does not comply with those requirements.

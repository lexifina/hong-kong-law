# 13. Fee for application for restoration of name to register for one or more types of minor works under one or more classes

The fee to be paid under section 18(2)(b) of the Minor Works Regulation for an application for the restoration of the name of a person to the register is—

- (a) if the highest class of minor works to which the application relates is class I— (L.N. 109 of 2019)

  - (i) for an application received during the concession period—$865; or

  - (ii) for an application received at any other time— $1,300; (L.N. 109 of 2019)

- (b) if the highest class of minor works to which the application relates is class II— (L.N. 109 of 2019)

  - (i) for an application received during the concession period—$610; or

  - (ii) for an application received at any other time— $915; or (L.N. 109 of 2019)

- (c) if the application relates to class III minor works only— (L.N. 109 of 2019)

  - (i) for an application received during the concession period—$290; or

  - (ii) for an application received at any other time— $435. (L.N. 109 of 2019)

(L.N. 94 of 2015)

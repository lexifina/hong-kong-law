# 11. Fee for registration as registered minor works contractor for one or more types of minor works under one or more classes

The fee to be paid under section 12(7) of the Minor Works Regulation for the registration of a person as a registered minor works contractor is—

- (a) if the highest class of minor works for which the person is registered is class I, $595;

- (b) if the highest class of minor works for which the person is registered is class II, $595; or

- (c) if the person is registered for class III minor works only, $410.

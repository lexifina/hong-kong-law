# 12. Fee for application for renewal of registration for one or more types of minor works under one or more classes

The fee to be paid under section 14(2)(b) of the Minor Works Regulation for an application for the renewal of the registration of a registered minor works contractor is—

- (a) if the highest class of minor works to which the application relates is class I, $1,130;

- (b) if the highest class of minor works to which the application relates is class II, $835; or

- (c) if the application relates to class III minor works only, $425.

(L.N. 94 of 2015)

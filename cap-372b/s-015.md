# 15. Insufficient accommodation on trains

(1) The Corporation shall not be liable for any failure to carry a passenger on any particular train or in any particular class of a compartment or carriage thereof where there is insufficient accommodation of a class for which a ticket has been issued.

(2) Where there is insufficient first class accommodation on any train for which a ticket has been issued a passenger holding a first class ticket may travel in ordinary class accommodation without the right to claim a refund of the appropriate difference in fare.
